your image, byte for byte

  1. the default images/default/Dockerfile jr2 up builds it and tags it by content
  2. beside a Machine workspace(body, { image: import.meta.resolve("./image") }) a package ships its image with its Machine
  3. brought customize(task, { image: "ghcr.io/you/toolchain:1.4" }) an image you bake and host; jr2 never builds it

At pod start jr2 mounts its runtime at /opt/jr2: the Harness, built on the pi agent toolkit. It adds no layer to your image, and your tools win on PATH.

You own the toolchain. jr2 brings the Harness.

what a Machine is made of

  1. input a schema for what starts a run. The Console draws its start form from it.
  2. events typed, with an audience: an Agent's picks and a human's answers never mix.
  3. agents model, instructions, workspace access. "none" can read and pick, nothing else.
  4. states invoke an Agent: the state's on becomes its Menu, served as MCP tools. invoke a gate: the run waits for a human.

Choose your own adventure: the Agent picks where it goes next, from defined states.

any model, chosen per Agent

  1. per Agent agent({ model: "anthropic/claude-sonnet-4-6" }) the definition: who the Agent is
  2. per Turn* input: { prompt, model: "local/qwen3.6-35b-a3b" } a state turns the dial: a cheap model for a small step
  3. per run jr2 run task --input '{ "prompt": "…", "model": "…" }' when the Machine takes it as input: task does

* a switch mid-conversation starts cold: the new model has no prompt cache

The kit never picks a vendor. You pick the model.
